Здесь восстановлен подробный продуктовый план из файла `kontragent_full_project_context_v2_2026-09-14.txt`, раздела `CURRENT PRODUCT ROADMAP — REVISED`, строки 18382–18414. В нём фазы **0–15**. Названия и состав направлений взяты из сохранённого плана. Русские пояснения, контрольные результаты и критерии закрытия ниже сформулированы при оформлении чек-листа; это не дословная цитата старых утверждённых критериев.

Этот документ не заменяет ROADMAP.md и не утверждает новый порядок работ. Нумерация подробного плана отличается от действующих фаз 1–10. Особенно важно: в старом плане админ-панель и автообновление стояли перед расширением источников; текущий roadmap уже ведёт работу по источникам. Автоматически переставлять задачи назад нельзя.

Фактические статусы берём из PROJECT_STATUS.md и проверенного кода. При обновлении статуса в рабочей сессии синхронизируем затронутые пункты здесь. Если документы расходятся — сначала сверяем код и результаты, а не выбираем более оптимистичный статус.

Обозначения: ✅ подтверждённый завершённый пункт; 🟡 частичная реализация; 🔵 дальнейший этап из прежнего плана; ⚪ готовность не подтверждена. Незакрытый `[ ]` означает «нужно сделать или подтвердить», а не обязательно «кода нет».

## Фаза 5. Бесплатная волна официальных источников

Зачем: наполнить карточку содержательными данными до дорогостоящих закупок.

Уже зафиксированы в текущем статусе: master registry, налоговая задолженность, доходы/расходы, среднесписочная численность и реестр МСП. Это не подтверждает полное покрытие всех компаний или сегодняшнюю актуальность базы на Mac.

Исходный расширенный перечень восстановлен ниже. Это **не автоматически утверждённый обязательный объём первого MVP**. Перед закрытием текущей фазы нужно выделить из него обязательный минимум и последующие волны.

- [x] REVEXP — импорт доходов и расходов ФНС, по текущему статусу.
- [ ] SNR — специальные налоговые режимы ЮЛ: модель, обработчик и описание набора созданы; массовый импорт и вывод требуют завершения/проверки.
- [ ] SNRIP — специальные налоговые режимы ИП: та же стадия готовности.
- [ ] Дисквалифицированные лица.
- [ ] Проверка статуса НПД через API.
- [ ] Единая основа лицензий, затем Роснедра.
- [ ] Реестр экспедиторов.
- [ ] Реестры Ространснадзора.
- [ ] ЕРКНМ — сведения о контрольных мероприятиях.
- [ ] Росздравнадзор.
- [ ] НОСТРОЙ / НОПРИЗ.
- [ ] Сертификаты и декларации соответствия — при подтверждённом правомерном машинном доступе.
- [ ] Профессиональные реестры Минюста.
- [ ] Другие отраслевые реестры — только при подтверждённой продуктовой/поисковой потребности.
- [ ] РНП / ЕИС — через проверенный допустимый способ доступа.

Для каждого источника пройти: описание и ограничения → модель/обработчик → загрузка → сопоставление ИНН → проверка количества и дат → подключение к карточке → тесты → сохранение результата.

Результат: источники не просто скачаны, а дают полезные сведения по конкретным компаниям.

Критерий закрытия: согласованный минимум источников доведён до результата. Техническую доступность, права использования и условия подключения проверять при реализации; архивный список не является их актуальной проверкой.

**Ближайший шаг:** массовый импорт SNR/SNRIP. Видимый результат блока — налоговые режимы в карточке с датой данных.
