# PHASE 3 SCOPE — Official Data Sources

Дата фиксации: 15.09.2026
Статус: согласованная граница текущей Фазы 3.

Этот документ фиксирует конечный объём Фазы 3, чтобы она не расширялась бесконечно за счёт новых реестров. Основной порядок разработки по-прежнему задаёт `ROADMAP.md`.

## Принцип

Фаза 3 закрывается, когда обязательный MVP-набор официальных источников доведён до полезного продуктового результата. Новый источник не добавляется в обязательный объём без отдельного решения.

Для каждого источника путь считается завершённым только после проверки всей цепочки:

`официальный источник → условия доступа → дата данных → ingestion/model либо live API contract → сопоставление → coverage/семантика отсутствия → service → aggregator → UI, если полезно → tests → реальные данные/live smoke-test → commit`

## WAVE 2 — углубление рисков после MVP CORE

- Федресурс / ЕФРСБ и банкротные события.
- Арбитражные/судебные данные.
- ФССП и исполнительные производства.
- Более глубокая интеграция РНП / ЕИС, если она была отложена.

Эти источники важны, но образуют отдельную большую предметную область событий, ролей сторон, истории и трактовки результатов. Они не должны бесконечно удерживать Фазу 3 открытой.

## INDUSTRY / ON DEMAND — отраслевые источники

Подключаются позже по реальной продуктовой потребности и применимости к конкретному виду деятельности:

- единая основа лицензий;
- Роснедра;
- реестр экспедиторов;
- реестры Ространснадзора;
- Росздравнадзор;
- НОСТРОЙ / НОПРИЗ;
- сертификаты и декларации соответствия — только при подтверждённом правомерном машинном доступе;
- профессиональные реестры Минюста;
- другие отраслевые реестры.

Целевой подход: будущий Regulatory Requirement Engine определяет по деятельности/сделке, какие специальные разрешения и реестры действительно нужно проверять, вместо показа десятков пустых блоков каждой компании.

## Критерий закрытия Фазы 3

Фаза 3 закрывается, когда:

- все безусловные пункты MVP CORE завершены по Definition of Done выше;
- по РНП / ЕИС принято документированное решение: подключено сейчас либо перенесено из-за ограничений доступа;
- для каждого готового источника зафиксированы дата/происхождение данных, покрытие и правила трактовки отсутствия записи либо режим live-проверки;
- полный набор тестов проходит;
- результаты сохранены в GitHub и отражены в `PROJECT_STATUS.md`.

После закрытия Фазы 3 дальнейшее расширение перечня источников не выполняется автоматически. Следующий основной этап — Фаза 4: нормализация и качество данных.
