# Summary Engine v2 wording

Version: `summary-engine-2.0.1`  
Status: implementation foundation; browser and 40-company acceptance pending.

## Client rules

- Overall labels are Russian: «Критический риск», «Высокий риск», «Требует внимания», «Существенных рисков не выявлено», «Недостаточно данных».
- Money uses `₽`; ordinary dates use `ДД.ММ.ГГГГ`.
- Missing date is described as absence of an actual date, never as «дата — дата не указана».
- Limitations are grouped into one block with source-specific reasons.
- Coverage limitations do not appear as material risk factors.
- Recommendations use concrete actions: obtain FNS evidence, finish FSSP, open court documents, verify a bankruptcy stage.
- Rule codes, dataset codes and raw values are placed only under «Источник и методика».
